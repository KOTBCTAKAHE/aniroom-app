# AniRoom для Android

Нативное приложение AniRoom (Kotlin + Jetpack Compose): смотрите аниме с друзьями синхронно.

- Вход и регистрация, профиль, друзья, уведомления (в т.ч. системные, пока приложение работает)
- Комнаты: создание, вход по коду или ссылке `aniroom.space/rooms/КОД`, «Сейчас смотрят», «Продолжить»
- Синхронный плеер на ExoPlayer (HLS), коррекция рассинхрона скоростью/перемоткой как на сайте
- Хост: пауза/перемотка/скорость, двойной тап ±10 с, пропуск опенинга, следующая серия, выбор серии и тайтла
- Чат: ответы свайпом, реакции, стикеры, «печатает…», повтор неотправленных
- Живые реакции, голосование «Ещё серию?», оценки серий
- Полноэкранный режим поворотом телефона, картинка-в-картинке, экран не гаснет во время просмотра
- Темы: светлая, сепия, тёмная; анимированный маскот Ани

## Сборка

GitHub Actions собирает `app-release.apk` при каждом пуше в `main` и публикует его в Releases.

Локально: `gradle :app:assembleRelease` (JDK 17, Android SDK 35).

Подпись: по умолчанию используется ключ `app/aniroom.jks` из репозитория. Для своей подписи добавьте секреты
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`
(после смены ключа приложение нужно будет переустановить).
